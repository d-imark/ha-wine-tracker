# Flexible Bilder BP3 (Detail-Galerie) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In der Detailansicht bei mehreren Bildern ein Hauptbild + Thumbnail-Streifen zeigen (read-only), sonst unverändert.

**Architecture:** Reine Frontend-Änderung in `index.html` (`openViewModal` nutzt eine neue `viewGalleryHtml`-Hilfsfunktion) + `style.css`. Datenquelle ist `w.images` aus `wine_json` (bereits von `viewFromCard` geladen). Kein Backend-Change.

**Tech Stack:** Jinja/Vanilla JS/CSS. Verifikation per Playwright (System-Chrome, `channel="chrome"`), Bilder via BP1-API vorab angelegt.

## Global Constraints

- Galerie nur bei **> 1 Bild**; bei 0/1 Bild bleibt das heutige Verhalten unverändert.
- Read-only (keine Verwaltung); keine Kategorie-Badges; keine Lightbox-Navigation.
- Pfade über `INGRESS + '/uploads/' + encodeURIComponent(filename)`; Ausgaben mit `escapeHtml`.
- Kein Backend/Schema-Change; vorhandene 414 Tests bleiben grün.

- [ ] **Step 2: `viewGalleryHtml` einfügen**

In `index.html` vor `function openViewModal` (oder direkt danach im selben `<script>`) einfügen:
```js
function viewGalleryHtml(w, ribbonHtml) {
  var imgs = w.images || [];
  var url = function(fn) { return INGRESS + '/uploads/' + encodeURIComponent(fn); };
  if (imgs.length > 1) {
    var mainSrc = url(w.image || imgs[0].filename);
    var thumbs = imgs.map(function(im) {
      var u = url(im.filename);
      var active = (u === mainSrc) ? ' vthumb-active' : '';
      return '<img class="vthumb' + active + '" src="' + u + '" alt="" loading="lazy" ' +
             'onclick="viewSelectThumb(this, \'' + u + '\')">';
    }).join('');
    return '<div class="view-photo-panel view-has-gallery">' + ribbonHtml +
      '<img id="viewMainImg" src="' + mainSrc + '" alt="' + escapeHtml(w.name) + '" ' +
        'onclick="openLightbox(document.getElementById(\'viewMainImg\').src)">' +
      '<div class="view-thumbs">' + thumbs + '</div>' +
    '</div>';
  }
  if (w.image) {
    return '<div class="view-photo-panel" onclick="openLightbox(\'' + url(w.image) + '\')">' +
      ribbonHtml + '<img src="' + url(w.image) + '" alt="' + escapeHtml(w.name) + '"></div>';
  }
  if (ribbonHtml) return '<div class="view-photo-panel view-no-image">' + ribbonHtml + '</div>';
  return '';
}
```

function viewSelectThumb(el, url) {
  var main = document.getElementById('viewMainImg');
  if (main) main.src = url;
  var strip = el.parentNode;
  if (strip) {
    strip.querySelectorAll('.vthumb').forEach(function(t) { t.classList.remove('vthumb-active'); });
  }
  el.classList.add('vthumb-active');
}
